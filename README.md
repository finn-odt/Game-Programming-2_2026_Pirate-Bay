# Pirate Bay

You're a pirate on the main island of a pirate hideout and you're mate has been captured by renegade skeletons. Now it is your duty to help him.
But you have no money, no weapons, or anything else with you. So come on, pirate, aye!

## The Project

This Game is an alternative exam assignment for *Game Programming 2* course in the second semester of the *Animation & Game* degree programme, teached by Martin Leissler.

The task was to put into practice all the topics covered in the lectures and create a playable game (experience):
1. Observer Pattern & Decoupling of Systems
2. Pathfinding with NavMeshs and AI Agents
3. Finite State Machines (FSM) for AI Behaviour
4. Scriptable Object (Flyweight Pattern) for an Inventory

For the main graphics, the *Synty POLYGON Pirate Pack* from Unity's Asset Store was used, as well as a Skybox from *Poly Haven* and manually adapted, royalty-free icons from the internet for the user interface.
In addition to the standard packages, the following Unity packages were used:
- Curved Text Easy
- Starter Assets - ThirdPerson | URP
- Wingman - Your Inspector's Best Friend
- Unity Constants Generator
- Tri Inspector
- AI Navigation
- Cinemachine
- Input System
- Newtonsoft Json
- Shader Graph
- Visual Effect Graph
